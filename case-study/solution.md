# Use Cases
## 1. FAQ Automation
User: Customer  
Description: Chatbot answers frequently asked questions instantly using knowledge base.
## 2. Order / Status Tracking
User: Customer  
Description: Chatbot provides real-time updates on order or request status.
## 3. Smart Escalation
User: Customer  
Description: Complex queries are escalated to human agents when chatbot confidence is low.
## 4. Agent Assist
User: Support Agent  
Description: AI suggests responses to agents to improve speed and consistency.
## 5. Ticket Automation
User: System  
Description: Automatically creates support tickets for unresolved queries.
